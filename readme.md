# ReVision

Application which allows you to acces the camera feed of the cameras on the vive pro eye VR headset

# Instructions

1 - Dodwnload the latest release from [here](https://github.com/Blue-Doggo/ReVision/releases)
2 - Unzip the archive
3 - Launch VRCFT with the SRanipal tracking module
4 - Wait for the eye tracking to initialize
5 - Uninstall the SRanipal tracking module
6 - Close SRanipal in the system tray
7 - Launch ReVision.App.exe
8 - The camera feeds are now exposed on http://127.0.0.1:4442/left & http://127.0.0.1:4442/right
